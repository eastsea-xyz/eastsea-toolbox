## 조작 경제학 (F-08의 실질)

혼합이 막는 것과 못 막는 것을 정확히 구분해야 한다:

| 공격자 | 공격 | 결과 |
|---|---|---|
| 주최자 | 유리한 시드만 공개(시뮬레이션 후) | **불가** — 시드는 참가 모집 전 커밋, 명단을 모른 채 고른 값 |
| 주최자 | 불리하면 리빌 거부 | **완결** — 리빌 마감 후 drawWithoutSeed가 prevrandao만으로 추첨. 시드는 버려지고 상금은 참가자에게 |
| 검증자(제안자) | prevrandao 조작 | **부분** — 시드를 모르므로 목표 인덱스를 조준할 수 없다. 무작위 시도 확률 1/N |
| 주최자+검증자 합작 | 시드 사전 공유 + prevrandao 조준 | **가능** — 하지만 상금은 참가비 풀 자체라 합작 수익이 우승자 몫 = 남의 참가비. 티켓을 사야 하고, 실패하면(블록을 놓치면) 남의 티켓값을 사는 꼴. 소규모 라플에서 경제적으로 무의미 |
| 주최자 | 자기 지갑들로 참가 몰이 후 리빌 | 시드를 알고 있으므로 **우승 인덱스는 prevrandao에만 의존** — 몰이로 N을 늘려도 기대값은 티켓 비율 그대로 (자기 티켓/전체). 우위가 없다 |

결론: 이 설계는 "단일 주체의 확률 왜곡"을 제거한다. 두 주체
합작은 이론적으로 남지만 상금 구조(참가비 환급형)상 기대 이득이
없다 — **상금이 내부 참가비로만 조달되는 한 조작의 수익원이
없다**는 것이 근본 방어다. 외부 상금(스폰서)이 붙는 순간 이 표를
다시 계산해야 한다.

## 불변식

테스트가 강제하는 성질 (`contracts/test/raffle/CommitRevealRaffle.t.sol`):

- **I1 우승자 ∈ 참가자**: 임의 인원·임의 prevrandao·두 추첨 경로
  모두에서 winner는 항상 players 원소다 (`test_fuzz_drawPaysAParticipantExactly`).
- **I2 상금 보존**: 우승자 수령액 == 티켓 수 × 가격 — **정확한
  등식**, 컨트랙트 잔액은 0 (동일 fuzz).
- **I3 결정론**: 같은 (시드, prevrandao, 명단)에서 우승자는 로컬
  재현과 정확히 일치 (`test_reveal_paysWinnerDeterministically`,
  `test_reveal_outcomeFollowsCommittedSeed`).
- **I4 1회 추첨**: drawn 후 reveal·drawWithoutSeed 모두 거부
  (`AlreadyDrawn`).

## CEI 흐름

```
reveal / drawWithoutSeed:
  1. drawn = true, winner = who       ← 플래그 먼저
  2. emit Drawn
  3. 상금 전액 전송                    ← 마지막
```

enter는 외부 호출이 없다 (msg.value 수령만). 상금 수신이 실패하는
우승자(수신 불가 코드)는 존재할 수 있지만 — 자기가 산 티켓의
우승이므로 수신 가능한 주소로 참가할 책임은 본인에게 있다.

## brake 매트릭스

| 함수 | brake 하 | 이유 |
|---|---|---|
| `enter` | 차단 | 신규 자금·참가 유입 — 제동의 대상 |
| `reveal` / `drawWithoutSeed` | 개방 | 판정·지급(탈출) — 막으면 풀이 잠긴다 |
